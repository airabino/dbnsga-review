# Demonstration Repository for Method Defined in "Multi-Objective Optimization of Mixed-Technology Transportation Networks Via a Generalized NSGA-II Framework"

## Structure
Data - stores data required to run example code including networks and equipment. If you want to run SFMTA you will need to unzip Data/SFMTA.zip.
Output - folder to store outputs whose contents are ignored by git
Paper - paper source
src - Python source code
